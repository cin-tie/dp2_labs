# Проект: Лабораторные работы по ДП2

## Описание

Веб-приложение для просмотра и демонстрации лабораторных работ по курсу ДП2. Проект позволяет удобно просматривать Jupyter Notebook через Streamlit.

## Установка и запуск

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
streamlit run app.py
```

## Функциональность

- Отображение Jupyter Notebook в веб-интерфейсе
- Визуализация графиков из notebook
- Отображение кода с подсветкой синтаксиса
- Навигация по частям лабораторных работ
